📜 サーバー利用ルール

ルール①

Java 版マイクラをマルチプレイをする場合、VPN へ接続をしていただきます。
セキュリティについては強く設定していますので、安心してください！
マルチプレイをするには PC が必要となります。

◆接続手順◆

  • ① SoftEther VPN Client をインストールします。（別でマニュアル作成済）
  • ② SoftEther VPN のアカウントをお伝えします。
  • ③ Java 版マイクラの IP アドレスを共有します。

※ VPN アカウントは絶対に SNS や第三者へ共有しないでください。

ルール②

VPN アカウントを正しく使ってほしいので注意項目を以下より確認してください。
SoftEther VPN では基本「ユーザー名」と「PW」でアクセスすることができます。
ですが特殊な設定にしています。接続先証明書を登録するため、クライアント (ユーザー側)の IP アドレスを管理者側で登録をかけています。
そのため、別の PC から VPN へアクセスしようとしても接続拒否されます。登録をかけた PC じゃないとアクセスはできません。

ログは常に AI を使って分析しているので、万が一、遊び感覚で別の PC からアカウントを入力してアクセスしようとすると不正アクセスと検知され、アクセス不可となるように設定しています。初期登録したら VPN 設定はいじらないでください！

特に注意してほしいのが、ノート PC やタブレット PC で Java 版マイクラをしているユーザーさんです。
友人や親戚の家、フリーWi-Fi(カフェ、ホテル、携帯キャリア店など)へネット接続をして VPN にログインしてしまうと、
IPアドレスが変わり、不正アクセス検知となり、アクセスすることができないので注意してください！
外出先からマイクラをプレイしたい場合は、統合版をプレイしてください。

※ あくまで自宅に光回線、コンセント型ルーターに契約しいる方が対象です。
ポケット Wi-Fi やスマホのテザリングは NG となります。

⚠️複数回不正アクセス検知すると VPN アカウントは 一時停止となります⚠️

ルール③

VPN アカウントとポータルサイトのアカウントも付与します。
ポータルサイトは VPN に接続しないと閲覧できないようになっています。
Java 版マイクラをプレイする前に必ずポータルサイトのお知らせ欄を確認してください。
メンテナンス中で起動しなかったり、PC 再起動で一時的にオフラインになっていることがあります。
その都度、お知らせへ投稿していくので確認お願いします！
